A minimalist, dark-themed personal portfolio website designed to showcase my software engineering projects, mobile applications, technical skills, and hardware setup. Built from scratch with a focus on clean layout structure, responsive design, and high-contrast typography.

---

## ✨ Key Features

* **Minimalist Dark UI:** High-contrast midnight navy (`#0a192f`) and mint accent (`#64ffda`) color palette engineered for readability and a modern developer aesthetic.
* **Custom Layout Architecture:** Built from the ground up using semantic HTML5 and modern CSS Flexbox/Grid without heavy framework bloat.
* **Responsive Navigation:** Clean, adaptive top navigation bar with smooth section anchoring and direct links to developer profiles.
* **Project & Hardware Showcases:** Dedicated sections highlighting native Android applications, software engineering work, and custom PC/peripheral setups.

---

## 🛠️ Tech Stack & Design System

* **Markup & Styling:** Semantic HTML5, Vanilla CSS3 (Custom Properties / CSS Variables, Flexbox)
* **Interactivity:** Vanilla JavaScript (ES6+)
* **Color Palette:**
  * Primary Background: `#0a192f`
  * Secondary Surface: `#112240`
  * Primary Accent: `#64ffda`
  * Text Primary / Secondary: `#ccd6f6` / `#8892b0`
